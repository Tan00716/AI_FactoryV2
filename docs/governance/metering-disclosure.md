## 一、单位与口径

计量单位只有三种，全部是 AI Factory 自有策略单位，不是厂商计价单位：

| 单位 | 含义 | 计什么 |
|---|---|---|
| usd-estimate | 美元估算 | 估算费用，不是账单金额 |
| calls | 调用次数 | 记录的用量调用次数 |
| tokens-estimate | token 估算 | 输入 token + 输出 token 的估算和 |

预算对象三级范围：task（任务）/ person（人）/ project（项目）。
预算周期四种：daily（每天）/ weekly（每周）/ monthly（每月）/ all-time（不限期）。
账本范围：每个预算只保留当前窗口，写时修剪旧窗口——这是策略账本，不是 billing 历史，
不要把它讲成对账单。持久化文件为 <DATA_DIR>/budgets.json（原子写，未知形状 fail-closed）。

默认预算（AI Factory 自有政策默认值，非厂商价格，来源 packages/quota/src/budget.ts
DEFAULT_BUDGET_POLICY，口径日期 2026-11-03）：

| 默认项 | 数值 | 来源与日期 |
|---|---|---|
| 新项目默认预算 | 10 美元估算 / 每月 | 自有政策默认值，2026-11-03 |
| 新任务默认预算 | 2 美元估算 / 不限期 | 自有政策默认值，2026-11-03 |
| 上限默认 | 开启（capEnabledByDefault: true） | 自有政策默认值，2026-11-03 |
| 自动续期默认 | 关闭（autoRenewDefault: false） | 自有政策默认值，2026-11-03 |
| 警告阈值 | 80% | 自有政策默认值，2026-11-03 |

已存在同范围 + 同键 + 同单位 + 同周期的预算时，apply-defaults 不覆盖。上限必须为有限正数，
零 / 负 / 无穷上限拒绝写入（fail-closed）。

## 二、耗项清单

计量对象是“记录的用量调用”本身，按四字段记录，不按功能拆分：

| 耗项字段 | 说明 |
|---|---|
| calls | 调用次数 |
| inputTokens | 输入 token 数（估算，除非 provider-reported） |
| outputTokens | 输出 token 数（估算，除非 provider-reported） |
| costUsd | 费用（估算，除非 provider-reported） |

一次用量记录归属到所有匹配范围的预算（任务 / 人 / 项目）。以下两项是现状，不是承诺：

- 不按功能拆分：补全、建议、采纳、忽略等功能维度不在计量口径内；不存在“仅按采纳计费”
  机制（那是第 9 项限流公平性设计稿的未来项，不是现状，不得把设计稿说法当成已实现）。
- 换算表不是计费项：下表三行是“估算换算系数”，用于在无实报时估算一次调用的量级，
  不是按次收费的价格。未知单位估算为 null，永不编数字。

| 换算行 | 输入 token（估算） | 输出 token（估算） | 费用（估算） | measured | 来源与日期 |
|---|---|---|---|---|---|
| chat-generation（一次 Chat 式生成） | 1000 | 500 | $0.01（估算） | false | 占位系数，2026-11-03 |
| code-edit（一次代码编辑） | 2000 | 800 | $0.02（估算） | false | 占位系数，2026-11-03 |
| agent-run-step（一次 Agent 运行步骤） | 4000 | 1500 | $0.05（估算） | false | 占位系数，2026-11-03 |

换算表每行附占位水印：“占位系数：待模型接通后实测填数，不得当作真实价格”。
面板（BudgetPanel）换算行每行另带“（估算）”标记，不得出现无标记美元数。

## 三、免费基线

本产品不存在厂商账单意义上的“免费额度”，不得编造免费档。免费基线只有以下两条，
每条都有实现或显性标注：

| 基线项 | 实现依据 |
|---|---|
| 不调用模型的工作不计预算 | 熔断只拒绝“新模型调用”；已在运行的确定性工作不受影响（budget.ts Breaker 语义） |
| 当前不产生真实账单 | 用量来源只有 simulated / manual（见第五节），无 provider-reported 行；StubAdapter 验证路径的模拟用量只证明熔断逻辑走得通，不是真实消费 |

反向说明：Codex 适配器存在但真实回路未实证（审计 #2 门控，待 Tan 登录），其余适配器为 stub。
在 #2 实证完成前，任何“已产生 X 美元真实消费”的说法均无依据，不得出现。

## 四、超限行为

| 阈值 | 行为 | 备注 |
|---|---|---|
| 80% | 每窗口警告一次（warned），不阻止调用 | 警告不拦停 |
| 100% | 熔断（tripped），拒绝新调用 | 只拦新调用，已运行的确定性工作不受影响 |
| 放行（released） | 每窗口恰好可放行一次，放行理由必填并记审计 | 放行只清除熔断状态，永不提高上限 |
| 熔断留痕 | 项目级预算熔断时 best-effort 进影子检查点（label 形如 budget-breaker:<id>） | 事后可查的断点，不是自动恢复 |

超限后无“付费续跑”默认选项：付费续跑分支只在第 9 项设计稿中留占位，计费存在后才启用，
现阶段不作默认选项、不参与默认决策。未决策期间的限流开关口径与信任决策（审计 #3）
同口径：未决策 = 暂停而非默认付费续跑。
触顶当前唯一可用默认 = 暂停；本地降级仅为未来选项（待 #2 本地通道通过实证后重议），
现阶段不与暂停并列为二选一默认，不得写成已可用。

## 五、估算声明

用量行来源三档，含义与当前状态：

| 来源标注 | 含义 | 当前状态（2026-11-03） |
|---|---|---|
| simulated | StubAdapter 验证路径记录的模拟用量；面板“记录用量（模拟）”按钮与服务端缺省来源均为 simulated | 存在，只证明熔断逻辑，不是账单 |
| manual | 人工登记的用量 | 存在，不是厂商回执 |
| provider-reported | 真实模型回执的用量；只有此标注的行可称为真实消耗 | 当前 0 行：Codex 未实证，其余适配器为 stub，视图内不得出现真实消耗数字 |

标记规则：一切非 provider-reported 数字永带 estimated 标记。面板侧已落实：

- CommandPanel 预算行每行强制带“估算”pill（command.estimated）。
- BudgetPanel 单位下拉与预算行单位列为“美元估算 / Token 估算”；费用输入框标注“费用估算（美元）”；
  换算行每行带“（估算）”标记（budget.estimatedSuffix），外加整块占位水印。
- 预算面板描述行（budget.desc）首段即声明“费用与 token 均为估算，除非用量源为 provider 上报”。

竞品费率不挪用：本页披露形状借鉴 Copilot 一页披露、JetBrains 座位与用量拆分、Cursor 封顶
机制的写法，但竞品费率（如 Copilot 的点数单价）不是本产品费率，本页不引用任何竞品费率
作为自身费率。自身费率目前不存在——换算表系数全部是占位值，待实报接通后实测填数。
