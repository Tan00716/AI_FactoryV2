# AI Factory 隐私政策与数据处理说明

> 版本：V3-#10（2026-10-30）。本文档描述 AI Factory 如何处理你的数据，
> 而不是营销承诺：凡是写了“不做”的，都有对应的实现或明确的未实现标注。

## 1. 数据驻留：本地优先

- 你的项目、任务、审计链、审批记录、知识库默认只落在本地：
  SQLite 数据库（`data/factory.db`）与 `.ai-factory/` 目录，不经过任何
  AI Factory 自营云端。本产品没有自营云端，也没有遥测、崩溃上报、
  使用统计外发（全树无 telemetry / sentry / posthog 产品级调用）。
- 唯一会离开本机的通道是你显式配置的外部目标：模型厂商 API、
  MCP 远程服务器、Webhook、出站搜索提供方——且全部受出站防火墙
  （默认收紧，见面板“出站防火墙”）与任务级范围锁定约束。
- 诊断包（见第 3 节）由你主动导出、保存在你指定的位置；
  导出动作本身只记一条审计（包 ID 与章节计数，不含包内容）。

## 2. 模型出境：调用即出境（占位文案）

- **现状占位**：当前版本除 Codex 外的模型适配器仍是 stub，
  真实模型 turn 尚未接通；因此本节目前是文案占位，不对应一次
  真实调用。
- **接通后的规则（已定，未生效）**：一旦模型接通，每次模型调用
  前 UI 都会明示“本次调用将把提示词与相关代码片段发送给
  〈厂商名〉”，并给出“不出境”的替代路径（本地 stub / 取消）。
  提示词、代码片段、任务描述都属于出境数据；密钥与 token 值
  在发送前由预发送密钥扫描拦截（R4-S1），拦截即记审计。
- 模型厂商侧的留存、训练使用与删除，遵循该厂商自己的政策，
  不在本产品的控制范围内；调用前明示会列出厂商名与政策链接。

## 3. 删除权与导出权

- **导出权**：诊断包导出（桌面“诊断包”面板）提供通用 JSON +
  HTML 报告：审计摘要、任务证据计数、脱敏配置快照、错误摘录、
  性能基线摘要。导出前有预览清单（列出含什么、不含什么），
  须你确认后才生成；包内绝不含密钥、token、环境变量、
  任务标题与文件内容。
- **删除权**：删除项目、任务或审计数据走产品内删除流程；
  归档数据按分层保留策略到期删除（见保留策略文档）。
  注意：审计链是防篡改的哈希链——单条审计记录不可“无痕”
  删除；删除操作本身会记一条审计，这是合规设计，不是缺口。
- **更正与询问**：对本文档的任何疑问，先看 `docs/KNOWN_LIMITATIONS.md`
  中的诚实边界清单；未列出的行为请视为未实现，不要假设。
